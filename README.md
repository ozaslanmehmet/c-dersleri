# TÜBİTAK Ortaokul Bilgisayar Olimpiyatı — Etkileşimli C Ders Notları

Bu depo, **TÜBİTAK Ortaokul Bilgisayar Olimpiyatı 1. Aşama** hazırlığı için hazırlanmış C programlama ders notlarını, etkileşimli kod çalıştırıcıyı, konu pekiştirme testlerini ve deneme sınavlarını içerir.

## Canlı Site (GitHub Pages)
👉 **https://ozaslanmehmet.github.io/c-dersleri/**

## Özellikler
- **7 Ana Ünite:** Değişkenler, Veri Türleri, İşleçler, Koşullar (`if-else`), `switch-case`, Döngüler (`while`, `do-while`, `for`, iç içe döngüler) ve Diziler (1D/2D).
- **Etkileşimli C Kod Çalıştırıcı:** Ders notlarındaki kodları doğrudan tarayıcıda düzenleyip GCC ile çalıştırabilme.
- **Konu Pekiştirme Testleri:** Anlık doğru/yanlış geri bildirimli çoktan seçmeli alıştırmalar.
- **4 Adet Deneme Sınavı (Orta & Zor):** Süre sayaçlı ve TÜBİTAK 4 yanlış 1 doğruyu götürür net hesaplamalı sınav modu.
- **İlerleme Takibi & Koyu/Açık Tema:** Öğrenci ilerlemesi tarayıcıda (`localStorage`) otomatik olarak saklanır.

## GitHub Pages Üzerinde Yayınlama
1. Depo ayarlarına (**Settings → Pages**) gidin.
2. **Source** bölümünden **Deploy from a branch** seçin.
3. Branch olarak `main` ve klasör olarak `/ (root)` seçip **Save** butonuna tıklayın.
4. 1–2 dakika içinde siteniz yayında olacaktır.
